# pairwise-ssr-pipeline

雨后的积水倒影在镜头转到屏幕边缘时整片消失，退回探针反射又突然变亮：SSR 只在屏幕空间步进，射线一出屏就丢弃，没有和探针、平面反射做权重混合；半分辨率反射用上一帧深度做厚度判断，角色移动后墙后物体被误判成遮挡；粗糙度只影响模糊半径，没有按材质各向异性重建 mip 链；法线从深度求导时没处理切线空间手性，斜面反射方向偏；双面材质只剔除背面，布料内层反射丢失；透明水面写深度又参与 SSR，自己遮自己；时域累积用固定 0.9 混合，快速转头时历史样本拖成鬼影；动态分辨率切换后 UV 和像素步长没重算，反射错位一截；异步 compute 读的是上一帧深度，和当前颜色缓冲不同步；分屏双相机共用一张反射图，右屏采样到左屏内容；射线步进固定 32 步，近处过采样远处漏采样；反射能量没有按菲涅尔和曝光重整，金属边缘过曝；GPU 资源在分辨率切换时销毁旧图但队列里还有引用。render/ssr_pipeline.py 是核心，tests/test_ssr_pipeline.py 15个红。要修的是：屏幕外回退与混合；多帧深度厚度；粗糙度 mip 链；切线空间法线；双面材质；透明深度分离；时域重投影；动态分辨率重算；异步 compute 同步；多相机隔离；自适应射线步进；菲涅尔能量；资源生命周期。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
